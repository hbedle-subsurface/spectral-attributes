# Terms used before the module that defines them

Generated by scanning every `<dt>` in the set against the prose of every
module, glossaries and Method sections excluded. Nineteen were found; the
seven worst were fixed by adding a definition where the term is first used.
These twelve remain.

| term | first used in | defined in |
| --- | --- | --- |
| `analysis window` | 01 spectrum | 02 windows |
| `reconstruction` | 01 spectrum | 03 components |
| `sidelobe` | 01 spectrum | 02 windows |
| `whitening` | 01 spectrum | 05 balancing |
| `matching pursuit` | 02 windows | 08 methods |
| `sparse inversion` | 02 windows | 08 methods |
| `spectral balancing` | 03 components | 05 balancing |
| `matching pursuit` | 04 tuning | 08 methods |
| `spectral balancing` | 04 tuning | 05 balancing |
| `peak magnitude` | 05 balancing | 06 attributes |
| `cumulative` | 06 attributes | 09 shadows |
| `matching pursuit` | 06 attributes | 08 methods |

Each is a term a module names once while pointing forward to where it is
treated, rather than a term a reader has to understand in order to follow the
step. `matching pursuit` in module 02 is the pattern: it is named as one of the
methods that exist, and module 08 is where it is explained.

Worth re-checking if the module order changes.
